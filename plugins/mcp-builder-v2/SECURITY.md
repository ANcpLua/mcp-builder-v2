# Security

Report a vulnerability privately through GitHub: open https://github.com/ANcpLua/mcp-builder-v2/security and select "Report a vulnerability". Please don't open a public issue for it.

Reports are answered in that private advisory. Fixes ship as a new plugin version on `main`, which the Claude plugin directory picks up from there.

The plugin has no hooks or MCP servers and collects no data; what its scripts run and contact is listed in [PRIVACY.md](PRIVACY.md).
